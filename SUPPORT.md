# Support

## Product issues

Use the repository issue tracker for ordinary non-sensitive product issues:

https://github.com/altrudev/living-architecture-nodes-action/issues

Include:

- Action release/tag;
- runner operating system;
- triggering event;
- `fail_on` / `changed_only` settings;
- checkout depth;
- a minimal reproduction where possible.

Do not include repository secrets, customer data, private source code, or vulnerability details in public issues.

## Security-sensitive reports

Use GitHub private vulnerability reporting:

https://github.com/altrudev/living-architecture-nodes-action/security/advisories/new

See [SECURITY.md](SECURITY.md).

## Scope

Support covers the Free GitHub Action's documented repository checks, outputs, client-safe local diagnostic export, and Marketplace behavior.

Commercial Living Architecture Nodes products and services have separate support/contract boundaries.
