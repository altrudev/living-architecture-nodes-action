# Support

## Product issues

Use the repository issue tracker:

https://github.com/altrudev/living-architecture-nodes-action/issues

Include:

- Action version/tag;
- runner operating system;
- triggering event;
- `fail_on` / `changed_only` settings;
- checkout depth;
- a minimal reproduction where possible.

Do not include repository secrets or private source code in public issues.

## Scope

v0.1.1 support covers the free GitHub Action's documented repository checks, outputs, local diagnostic export, and Marketplace package behavior.
